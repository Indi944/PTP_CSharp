# Aula_1_CSharp

Primeiro projeto C# Windows Forms desenvolvido na disciplina de PTP (Programação de Telemática e Programação).

## Descrição

Aplicação Windows Forms em .NET Framework (net48) com um formulário simples que contém um botão "Clica em mim". Ao clicar no botão, é apresentada uma MessageBox com a mensagem "Olá, Mundo!".

## Como executar

1. Abra a solução `Aula_1_CSharp.sln` no Visual Studio.
2. Compile e execute o projeto (F5).

Ou via linha de comandos:

```
dotnet build
dotnet run --project Aula_1_CSharp
```

## Requisitos

- .NET Framework 4.8 (já incluído no Windows 10/11 atualizado)
- Visual Studio 2019 ou superior, ou .NET SDK
