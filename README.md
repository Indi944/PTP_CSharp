# Aula_1_CSharp

Projeto de escolar em C# — aplicação Windows Forms em .NET Framework.

## Descrição

Aplicação Windows Forms desenvolvida em C# para .NET Framework 4.8. O projeto contém um único formulário (`Form1`) com um botão chamado **"Clica em mim"**.

## Como abrir e executar

1. Abra o **Visual Studio**.
2. Abra a solução **`Aula_1_CSharp.sln`** (Ficheiro > Abrir > Solução).
3. Carregue em **F5** para compilar e executar.

## Comportamento esperado

Ao carregar no botão **"Clica em mim"**, aparece uma caixa de mensagem (MessageBox) com o texto:

```
Olá, Mundo!
```

## Requisitos

- Visual Studio com a carga de trabalho **Desenvolvimento de aplicações em C#** (.NET desktop)
- .NET Framework 4.8 (incluído no Windows 10/11 atualizado)
